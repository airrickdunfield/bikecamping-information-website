# Bikecamping Website

## Overview
This is a new project that is a companion project to my bikecamping (bicycle) map that I've made to show off locations in BC. That project is a web app, where this project serves more as a informational site.  It will contain a Home page, an About Page, Gear Page with the following sub pages: Bikes, Bags, Tents and a Community groups page. The content for those pages will begin as dummy content which I will write later. This project serves as a staring point for a new bike camper

## Target User
This website has two important users. I am the first user who is a developer with minimal coding experience who is building this project with the help of AI, please make sure to talk to me in a way I can understand as you work. The other is people who are curious about bike camping, but haven't gotten started yet. When reviewing my writing, make sure it isn't filled with jargon and is easy read

## Tech Stack
React.js is the website type I'd like to use. Eventually I would like to use WORDPRESS to manage the data, but for now it's just react. For an animation library, research the library that is most used with React.js and use it consistently across the project. If you are adding a library or revising over 500 lines of code, check in with me before you do that.

## Constraints
Always write code in a way that is human readable and includes comments. When taking direction, prioritize my general descriptions over my technical terms as I am not an experienced developer.
